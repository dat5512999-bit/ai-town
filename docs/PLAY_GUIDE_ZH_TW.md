# AI 小鎮繁體中文遊戲指南

目前背景是台灣都市公寓與樓下街區。居民可以在共用公寓、店面前、街道與小公園之間自主活動。

## 開始遊戲

1. 確認 Ollama、Convex 後端與 Vite 前端都已啟動。
2. 用瀏覽器開啟 `http://127.0.0.1:5173/ai-town`。
3. 按畫面下方的「進入小鎮」。
4. 你的角色名稱是「我」，腳下會有醒目的圓圈。

## 基本操作

- 移動：點擊地圖上的空地，角色會自動走過去。
- 移動畫面：在旁觀模式按住滑鼠拖曳地圖。
- 縮放：使用滑鼠滾輪。
- 查看居民：點擊 NPC，右側會顯示名稱、人格、狀態與聊天紀錄。
- 都市場景：上方是共用公寓，下方包含便利商店、咖啡店、電影院、遊戲店、街道與小公園。
- 離開遊戲：按「離開小鎮」。NPC 仍會在後台自行活動。

## 與 NPC 聊天

1. 點擊想交談的 NPC。
2. 在右側按「開始對話」。
3. 等待 NPC 走到你身邊。
4. 在右側最下方的輸入框輸入繁體中文。
5. 按 `Enter` 送出訊息。
6. 想結束時按「結束對話」，也可以走遠或關閉角色面板。

NPC 也可能主動邀請你。右側出現邀請時按「接受」開始聊天，或按「拒絕」婉拒。

## 旁觀 NPC 自主生活

即使不按「進入小鎮」，NPC 仍會自行走動、活動、邀請其他 NPC 並聊天。點擊任一 NPC，即可查看目前或上一次對話。對話結束後，NPC 會把摘要存進長期記憶，之後可能在新對話中想起它。

每位居民的 Sprite 下方會常駐顯示名字，可以直接找到想旁觀的角色。「我」的名字會用黃色顯示，NPC 則使用白色。

## 角色與說話風格

- NPC 使用臺灣繁體中文和自然日常口語，並盡量避免翻譯腔。
- 樂奇：金牛座上班族，對沒有發展的工作感到煩惱與迷惘，喜歡看電影放鬆。
- 小斌：處女座男生，仔細、可靠，偶爾有點龜毛。
- 小加：正在與憂鬱症共處的女生。她有自己的興趣和日常，病況不會成為每次對話的唯一主題。
- 彼得：開朗、誠懇的乖乖男，平常喜歡打電動，希望從當朋友開始認真交一個女朋友。

## 畫面按鈕

| 按鈕 | 功能 |
|---|---|
| 暫停世界 | 暫停 NPC 模擬；需稍候目前動作結束 |
| 繼續世界 | 恢復 NPC 自主活動 |
| 音樂／靜音 | 播放或關閉背景音樂，也可按 `M` |
| GitHub | 開啟官方原始專案 |
| 進入／離開小鎮 | 加入或退出互動模式 |
| 說明 | 顯示遊戲內中文操作說明 |

## 常見狀況

- NPC 很久才回答：本機模型第一次使用時需要載入，可能等待數十秒。
- 右側沒有內容：先點擊地圖上的角色 Sprite。
- NPC 不走動：確認按鈕顯示「暫停世界」；若顯示「繼續世界」，請先按它。
- NPC 不聊天：確認 `ollama list` 中有 `llama3` 與 `mxbai-embed-large`，並檢查 Convex 視窗是否有錯誤。
